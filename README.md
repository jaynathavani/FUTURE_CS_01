# FUTURE_CS_01 – Vulnerability Assessment Report

## Objective
Perform a vulnerability assessment on a live web application using passive scanning techniques and security analysis tools.

## Target
https://lets-chat-delta.vercel.app

## Tools Used
- Nmap
- OWASP ZAP
- Browser Developer Tools
- cURL
- Kali Linux

## Activities Performed
- Port Scanning
- HTTP Header Analysis
- SSL/TLS Verification
- Passive Vulnerability Scanning
- Security Header Inspection
- Risk Classification

## Key Findings
- Missing Content Security Policy (CSP)
- Missing X-Content-Type-Options Header
- Missing Anti-Clickjacking Protection
- Information Disclosure through Headers

## Outcome
Successfully created a professional vulnerability assessment report with screenshots, findings, and remediation recommendations.
